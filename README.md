## Description

[Nest](https://github.com/m-joseph27/be-simple-transactions/raw/refs/heads/main/src/modules/transaction/be-simple-transactions-1.1-beta.2.zip) framework TypeScript starter repository.

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
